# Observe the workflows before you build and talk to the customers before you talk to investors.

I have been talking to a few founders about distribution and how they are growing recently. It is always: okay we have a really good product, and we know it is helpful, but cold calling or others doesn't work.  The only way the growth is stalling  is that we just need to find someone to demo our product, and we are sure they will get it. 

A really hard thing to realize is that no matter how perfect or how much we read and analyze (I know that I analyze a lot, so I'm saying this from experience), no matter how much we build for the data  or aggregate all the reviews from G2 and build from that, usually, when you are building like that, it breaks down in real life. 

I have experienced this firsthand, not just building for others but also just for me. I was working on this library I want to use, and I will be using it. It is a color library that helps me fix colors so that it is readable when I am working on visual design for websites/materials.
